# Salon Namestaja - Delphi Aplikacija

Aplikacija u Delphi-u sa SQL Server bazom.

## Opis
Ova aplikacija služi za vođenje evidencije računa u salonu nameštaja. 
Omogućava kreiranje računa, dodavanje stavki, obračun PDV-a i pretragu.

## Funkcionalnosti
- Kreiranje novih računa
- Dodavanje stavki na račun
- Automatski obračun PDV-a (20%)
- Pregled svih računa
- SQL Server baza podataka

## 🔧 Tehnologije
- Delphi RAD Studio 13
- SQL Server
- ADO komponente za pristup bazi
